# Explore Switzerland 🇨🇭

Site informativo e responsivo sobre destinos turísticos da Suíça, desenvolvido como projeto acadêmico de Desenvolvimento Web.

## Objetivo

Apresentar diferentes regiões da Suíça, experiências de viagem e informações iniciais para quem deseja conhecer o país. O conteúdo tem caráter introdutório e reúne referências para continuar o planejamento em fontes oficiais.

## Tecnologias utilizadas

- **HTML5:** estrutura semântica e organização do conteúdo.
- **CSS3:** identidade visual, layouts, animações e responsividade.
- **JavaScript:** menu mobile, filtros, busca, modais dinâmicos, FAQ e atualização do ano no rodapé.

## Funcionalidades

- Navegação por seções da página e menu responsivo para dispositivos móveis.
- Galeria com **9 destinos**: Lucerna, Interlaken, Zermatt, Berna, Genebra, Montreux, Lugano, Lauterbrunnen e Grindelwald.
- Filtros por categoria: cidades, lagos e vilas, natureza e montanhas.
- Campo de busca para localizar destinos por nome ou conteúdo.
- Modais com descrição, principais atrações e sugestões de época para visitar cada destino.
- Seção de experiências, roteiro sugerido de 7 dias e informações sobre as estações do ano.
- Área de planejamento com informações sobre moeda, idiomas, transporte, hospedagem e links oficiais.
- Perguntas frequentes em elementos expansíveis.
- Layout adaptado para computadores, tablets e celulares.

## Como executar

1. Baixe ou extraia os arquivos do projeto.
2. Abra a pasta `Explore-Switzerland` no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.

Não é necessário instalar dependências nem executar um servidor para visualizar a versão básica do site. A conexão com a internet é necessária para carregar as fontes externas e acessar os links oficiais.

## Observações

- O roteiro é uma sugestão inspiracional e deve ser adaptado às datas, conexões e ritmo de cada viagem.
- Custos, horários, disponibilidade de atrações, trilhas e teleféricos podem mudar. Consulte os fornecedores oficiais antes de viajar; o site não apresenta cotações em tempo real.
- A imagem principal `hero-novo.jpg` e as seis imagens adicionadas aos cartões de destino são ilustrações geradas por IA para fins de apresentação do projeto. As imagens originais de Lucerna, Interlaken e Zermatt foram preservadas.
